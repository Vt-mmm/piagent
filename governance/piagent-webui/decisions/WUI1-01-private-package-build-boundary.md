# WUI1-01 private package and build boundary

## Decision

Create `packages/piagent-webui` as a private npm workspace using React,
TypeScript and Vite. This item establishes only the browser build, generated
contract boundary, architecture layers and distribution exclusions. It does not
start a listener, expose an HTTP route, read runtime state or claim a usable
product surface.

## Contract generation

- `schemas/piagent-webui/catalog-v1.json` remains the only catalog authority.
- Browser TypeScript declarations are deterministic generated artifacts.
- Generation resolves sibling schema references locally and never fetches a
  remote schema.
- `check:contracts` compares generated bytes with committed artifacts and fails
  on drift.
- Generated declarations are compile-time aids, not runtime validation or a
  second wire contract.

## Package boundary

- The package is `private: true` and has no publish script.
- The root public npm artifact excludes `packages/piagent-webui` during this
  milestone.
- Client source may import browser-safe generated contracts only. It cannot
  import Node built-ins, server code or `piagent-core` runtime modules.
- Server source may later import generated contracts and approved runtime
  projection/security modules; runtime/core cannot import WebUI.
- Bundles use local assets only: no CDN, analytics, service worker or runtime
  remote module loading.

## WUI1-01 acceptance

1. Clean contract generation is deterministic and drift detection fails on a
   changed artifact.
2. Package typecheck and production build pass.
3. Architecture checks include the new package and reject client-to-server or
   runtime-to-WebUI imports.
4. Root packaging proves the private WebUI source/build is absent.
5. Static inspection proves this item has no network listener, mutation route or
   second Pi runtime path.
6. Existing Inspector/runtime behavior and zero-turn contracts remain unchanged.

## Rollback

Remove the private workspace, generated declarations and WebUI architecture
entries. No persisted state, migration or runtime fallback is required.
