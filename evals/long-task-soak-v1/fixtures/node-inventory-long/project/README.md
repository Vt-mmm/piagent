# kho-hang

Thư viện quản lý tồn kho cho chuỗi cửa hàng nhỏ. Đặc tả đầy đủ ở `SPEC.md`.

```bash
npm test
```

- `src/index.js` — thư viện tồn kho (đang làm theo `SPEC.md`).
- `src/legacy/report-engine.js` — module báo cáo cũ (2019–2024), phòng kế
  toán và cửa hàng vẫn đọc output của nó. Đừng sửa khi chưa được giao.
- `data/stock-2025.csv` — dữ liệu tồn kho năm 2025 xuất từ hệ thống cũ (Excel).
