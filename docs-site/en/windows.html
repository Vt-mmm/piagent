Piagent on Windows with one command

One PowerShell command installs WSL2, Ubuntu, Piagent and Agent Watch, binds the company key and adds Piagent to the Start menu; run it again to update.

Install with one command

Open PowerShell (Start → type PowerShell) and run:

One command
irm https://raw.githubusercontent.com/Vt-mmm/agentwatch/main/windows/setup.ps1 | iex

It goes through these steps:

  1. Installs WSL2 when it is missing. Windows asks for administrator approval; the first time a restart is needed, and setup continues when you sign in again.
  2. Installs Ubuntu, creates an Ubuntu user named after your Windows user and asks for its password (used for sudo).
  3. Installs Piagent inside Ubuntu: system packages, the bubblewrap sandbox, Node 24, Piagent and the Pi version the release pins.
  4. Asks for the connection code your admin sent. With a code it installs Agent Watch, connects the company key and binds Piagent in Ubuntu to it. Press Enter to skip if you only use your own AI account.
  5. Adds a Piagent entry to the Start menu and opens the dashboard in the browser.

Updating: run the same command again. Finished steps are skipped; Piagent and Agent Watch are updated and the company key is bound again.

Agent Watch is an internal build without a code signature: if Windows SmartScreen warns, choose More info → Run anyway.

Every day

Open Piagent from the Start menu: an Ubuntu window opens the dashboard in the Windows browser. Keep that window open while you work.

Keep projects on the Ubuntu disk (for example ~/projects) for speed; Windows folders (/mnt/c/...) work but are much slower for npm and git. VS Code on Windows opens folders inside Ubuntu through its WSL extension.

When setup fails

Symptom What to do
Setup asks for a restart after every restart, or Ubuntu fails with 0x80370114 Windows reads Virtual Machine Platform as enabled but lacks its VM service. If Test-Path C:\Windows\System32\vmcompute.exe prints False: in PowerShell opened with Run as administrator run DISM /Online /Cleanup-Image /RestoreHealth and sfc /scannow, then turn VirtualMachinePlatform off and on again with dism.exe (restart each time). Still missing: repair-install Windows 11 with the Installation Assistant, keeping files and apps.
0x80370102 or a virtualization error Turn on virtualization (Intel VT-x / AMD SVM) in the BIOS.
Downloading Ubuntu fails wsl --install -d Ubuntu --web-download, then run setup again.
The dashboard says Agent Watch or Piagent changed Run setup again, or choose Kết nối Piagent trong WSL (Connect Piagent in WSL) in Agent Watch.

Check the machine with piagent studio --doctor inside Ubuntu. When Windows still lacks the VM service after a restart, setup prints the repair steps above instead of asking for another restart.

Why WSL2

Ubuntu in WSL2 runs inside Windows as a lightweight virtual machine that Windows manages; it is not a second operating system to boot. Company mode needs an operating-system sandbox around every command the agent runs: Seatbelt on macOS, bubblewrap on Linux and WSL2. Windows has no equivalent sandbox yet, so Piagent runs in WSL2.

Running on Windows itself (without WSL) is a preview of personal mode. Manual steps and sandbox details: Piagent on Windows.
