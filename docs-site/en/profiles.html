Technology stack by role

Frontend profiles select frontend technology and an optional database; backend profiles select backend technology and an optional database; full-stack profiles select frontend, backend, and database. The platform then writes .pi/tech-stack.json and a compact Context7 snapshot under .pi/tech-context/*.
