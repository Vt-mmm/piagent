Install

Requires Node.js 22.19.0 or later. You do not need Pi first: piagent-setup installs the exact Pi release this version pins, initializes .pi/, installs the MCP baseline and subagents, then runs the doctor.

Run in the project folder
npm install -g @piagent/platform
piagent-setup
PowerShell
irm https://raw.githubusercontent.com/Vt-mmm/agentwatch/main/windows/setup.ps1 | iex

Installs WSL2, Ubuntu, Piagent and Agent Watch. Details in Windows.

Skip the extras with --no-mcp, --no-subagents, --no-herdr or --global-only.

Open a project

Terminal and the dashboard share one history. Company mode opens with piagent studio once the key is imported through Agent Watch.

Pick one
piagent dashboard          # browser, personal mode
pi                         # Terminal, personal mode
piagent studio --web       # company mode

Let the agent read the project

In a new repository, ask the agent to read it (read-only) and record the project context in .pi/. No special command is needed.

First message
Read this project (read-only) and record the project context.

Pick a profile and permission

The profile decides which files are protected and which checks run. Permission: read-only to explore, workspace-write for normal coding.

Slash commands
/profile setup
/permission workspace-write

Ask in plain language

Say what you need and how: edit, read-only, or plan first. For context-heavy work, start a fresh session with /new.

Examples
Fix the pagination bug in /orders, then run the project's tests.
Review the current diff. Read-only.

Check the installation

After installing or changing releases, run the doctor on the project. Every finding comes with the fix.

piagent-doctor

Using Herdr?

Install Herdr before piagent-setup to get its Pi integration; if you install it later, run piagent-setup --global-only again. On Windows, install Herdr inside Ubuntu (WSL2), next to Piagent; in a Herdr pane, piagent studio comes back to the same company conversation after Herdr restarts. Herdr arranges terminals; it is not a protection layer. See the Herdr workflow.
