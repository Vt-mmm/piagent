Cài bằng một lệnh

Mở PowerShell (Start → gõ PowerShell) và chạy:

Một lệnh
irm https://raw.githubusercontent.com/Vt-mmm/agentwatch/main/windows/setup.ps1 | iex

Lệnh này lần lượt:

  1. Cài WSL2 nếu máy chưa có. Windows hỏi quyền quản trị; lần đầu cần khởi động lại, và cài đặt tự chạy tiếp khi bạn đăng nhập lại.
  2. Cài Ubuntu, tạo user Ubuntu theo tên Windows của bạn và hỏi mật khẩu cho user đó (dùng khi chạy sudo).
  3. Cài Piagent trong Ubuntu: gói hệ thống, sandbox bubblewrap, Node 24, Piagent và đúng bản Pi mà release đang pin.
  4. Hỏi mã kết nối admin gửi. Dán vào thì lệnh cài Agent Watch, kết nối key công ty và nối Piagent trong Ubuntu với key đó. Bấm Enter để bỏ qua nếu bạn chỉ dùng tài khoản AI của riêng mình.
  5. Thêm mục Piagent vào Start menu và mở dashboard trong trình duyệt.

Cập nhật: chạy lại đúng lệnh trên. Những bước đã xong được bỏ qua; Piagent và Agent Watch được cập nhật và nối lại key công ty.

Agent Watch là bản nội bộ chưa ký số: nếu Windows SmartScreen cảnh báo, chọn More info → Run anyway.

Dùng hằng ngày

Mở Piagent từ Start menu: một cửa sổ Ubuntu mở dashboard trong trình duyệt Windows. Giữ cửa sổ đó mở khi đang dùng.

Để project trong ổ của Ubuntu (ví dụ ~/projects) cho nhanh; folder Windows (/mnt/c/...) vẫn dùng được nhưng chậm hơn rõ với npm và git. VS Code trên Windows mở thẳng folder trong Ubuntu qua extension WSL.

Khi cài bị lỗi

Dấu hiệu Cách xử lý
Lệnh đòi khởi động lại mãi, hoặc Ubuntu báo 0x80370114 Windows ghi đã bật Virtual Machine Platform nhưng thiếu dịch vụ máy ảo. Nếu Test-Path C:\Windows\System32\vmcompute.exe ra False: trong PowerShell Run as administrator chạy DISM /Online /Cleanup-Image /RestoreHealth và sfc /scannow, rồi tắt và bật lại VirtualMachinePlatform bằng dism.exe (mỗi lần Restart). Vẫn thiếu: cài đè Windows 11 bằng Installation Assistant, chọn giữ file và ứng dụng.
0x80370102 hoặc lỗi ảo hoá Bật Virtualization (Intel VT-x / AMD SVM) trong BIOS.
Tải Ubuntu lỗi mạng wsl --install -d Ubuntu --web-download, rồi chạy lại lệnh cài.
Dashboard báo Agent Watch hoặc Piagent vừa cập nhật Chạy lại lệnh cài, hoặc trong Agent Watch bấm Kết nối Piagent trong WSL.

Kiểm tra máy: trong Ubuntu chạy piagent studio --doctor. Khi máy đã khởi động lại mà Windows vẫn thiếu dịch vụ máy ảo, lệnh cài in đúng các bước sửa ở trên thay vì đòi khởi động lại tiếp.

Vì sao là WSL2

Ubuntu trong WSL2 chạy ngay bên trong Windows như một máy ảo nhẹ do Windows quản lý, không phải cài song song. Chế độ công ty cần sandbox của hệ điều hành cho mọi lệnh agent chạy: Seatbelt trên macOS, bubblewrap trên Linux và WSL2. Windows chưa có sandbox tương đương, nên Piagent chạy trong WSL2.

Chạy thẳng trên Windows (không qua WSL) mới là bản xem trước cho chế độ cá nhân. Cài từng bước bằng tay và chi tiết sandbox: Piagent trên Windows.
