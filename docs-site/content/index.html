Khác biệt

Agent làm nhanh. Platform giữ cho nó làm đúng.

Mọi tool call đi qua guard, mọi việc rủi ro chờ bạn duyệt, và ở chế độ công ty, kết quả chỉ được báo là xong khi check đã chạy trên code cuối.

{{icon:shield-check}}

Guard trên mọi tool call

Fail-closed: file bảo vệ, profile quyền, file quá lớn, sửa trên bản đọc đã cũ. Sai thì chặn, không đoán.

✕ read .env — protected path
✕ edit src/app.ts — đọc lại trước khi sửa
! git push — chờ duyệt một lần
✓ npm test — được phép

Harness của team tự check và review

Studio đặt kế hoạch, check và số vòng review cho cả team. Subagent đọc diff độc lập; kết quả nằm ngay dưới câu trả lời.

Duyệt từng lần

Push, publish, lệnh có mạng chỉ chạy sau khi bạn bấm Cho phép một lần. Không có "luôn cho phép".

{{icon:box}}

Sandbox ở chế độ công ty

Seatbelt trên macOS, bubblewrap trên Linux và WSL2: không mạng, không đọc Keychain, .env hay SSH key.

{{icon:code}}

Dashboard là editor

Cây thư mục, editor, terminal, review từng hunk, Timeline khôi phục lượt và /undo. 13 theme màu.

{{icon:clock}}

Task dài không bỏ dở

Model lỗi tạm thời thì tự hỏi lại; Studio cập nhật thì chờ rồi làm tiếp. Một lượt chạy được tới 24 giờ.
