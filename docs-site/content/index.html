Cài trong hai lệnh

Node.js >=22.19.0. Chạy từ đúng project muốn set up.

npm install -g @piagent/platform
piagent-setup

piagent-setup cài đúng Pi Coding Agent host mà release này pin, cài Pi package, khởi tạo thư mục hiện tại, rồi chạy doctor. Nó cũng cài MCP baseline và subagents — bỏ qua bằng --no-mcp, --no-subagents hoặc --global-only. Chi tiết ở Quickstart.
