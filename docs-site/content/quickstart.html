Cài đặt

Cần Node.js 22.19.0 trở lên. Không cần cài Pi trước: piagent-setup tự cài đúng bản Pi mà release này pin, khởi tạo .pi/, cài MCP baseline và subagent, rồi chạy doctor.

Chạy trong thư mục project
npm install -g @piagent/platform
piagent-setup
PowerShell
irm https://raw.githubusercontent.com/Vt-mmm/agentwatch/main/windows/setup.ps1 | iex

Cài WSL2, Ubuntu, Piagent và Agent Watch. Chi tiết ở Cài trên Windows.

Bỏ bớt phần cài thêm bằng --no-mcp, --no-subagents, --no-herdr hoặc --global-only.

Mở project

Terminal và dashboard dùng chung một lịch sử. Chế độ công ty mở bằng piagent studio sau khi đã nhập key qua Agent Watch.

Chọn một
piagent dashboard          # trình duyệt, chế độ cá nhân
pi                         # Terminal, chế độ cá nhân
piagent studio --web       # chế độ công ty

Cho agent đọc project

Ở repo mới, nhờ agent đọc (chỉ đọc) và ghi project context vào .pi/. Không cần lệnh riêng.

Tin nhắn đầu tiên
Đọc project này (chỉ đọc) và ghi lại project context.

Chọn profile và quyền

Profile quyết định file nào được bảo vệ và check nào chạy. Quyền: read-only để khảo sát, workspace-write để code bình thường.

Slash command
/profile setup
/permission workspace-write

Giao việc bằng lời thường

Nói rõ việc và ý định: sửa, chỉ đọc hay lập plan. Việc nặng context thì mở session mới bằng /new.

Ví dụ
Sửa lỗi phân trang ở /orders rồi chạy test của project.
Review diff hiện tại. Chỉ đọc.

Kiểm tra cài đặt

Sau khi cài hoặc đổi bản, chạy doctor trên project. Lỗi nào cũng kèm cách sửa.

Doctor
piagent-doctor

Hệ điều hành được hỗ trợ

Môi trườngTrạng thái
macOS Apple SiliconĐã kiểm chứng cho release này.
Linux x64Đã kiểm chứng trong CI.
macOS Intel, Linux ARM64Hỗ trợ; chạy doctor và smoke test trước khi rollout rộng.
Windows (WSL2)Cách chạy Piagent trên Windows, cả chế độ cá nhân và công ty.
Windows nativeBản xem trước cho chế độ cá nhân; chưa có piagent-update.
Dùng Herdr?

Cài Herdr trước piagent-setup để được cài luôn tích hợp Pi; cài sau thì chạy lại piagent-setup --global-only. Herdr chỉ điều phối terminal, không phải lớp bảo vệ. Xem Herdr workflow.
