Workflow impact

Không có command bắt buộc mới trong daily flow

Từ bản 1.9.0, giao việc chỉ cần một yêu cầu bằng lời thường. /workflow, /task, /fresh và /onboard đã bỏ cùng task contract: session không còn ghi contract, work plan, completion gate hay receipt. Guard vẫn kiểm tra từng tool call.

Kết luận ngắn

Nói điều mình cần, kể cả agent có được sửa hay không ("chỉ đọc, không sửa", "lập plan trước", "implement rồi chạy test"). Các command xem thêm bên dưới là tùy chọn và không bao giờ mở lượt model.

Command semantics

Command xem thêm ảnh hưởng workflow đến đâu

CommandĐọc hoặc hiển thịKhông thực hiện
/task-preflightContext và shadow route deterministic cho một intent.Không tạo gì, không gọi model và không cấp quyền implementation.
/piagent-statusProfile, guard, runtime và trạng thái model đã xác thực.Không sửa file, không chạy lại verify và không retry.

Chỉ opt-in mới đổi hành vi.

Năm command trên là read-only. Hành vi chỉ đổi khi operator chủ động bật setting như helper mode; parent routing, automatic worker và multi-writer vẫn không tự bật.

Daily example

Một luồng đầy đủ có thể dùng như sau

Inspect → implement → review
/task-preflight --json Fix the failing checkout test
Sửa test checkout đang fail rồi chạy test của project.
/piagent-inspector
Review diff hiện tại: correctness, test còn thiếu, scope drift. Chỉ đọc.
/usage efficiency

Chỉ các dòng lời thường mới mở việc cho model. Preflight, inspector và efficiency là màn hình xem tùy chọn.

Git trong Pi Agent

Không có namespace /git và không có command workflow. Nhờ commit hoặc tạo PR bằng lời thường. git push, thao tác ghi lên GitHub và stage rộng như git add -A vẫn cần operator xác nhận.

Parent-direct orchestration

Dùng /piagent-orchestration để xem trần helper, lý do dispatch/skip, review lenses, Field Guide và writer policy. Helper mặc định off. Khi opt-in, parent được dùng tối đa hai helper read-only context fresh; ước tính tiết kiệm token chỉ là telemetry, không phải điều kiện. Worker và retry bị tắt.
