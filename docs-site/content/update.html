Cập nhật

Dashboard và Terminal kiểm tra bản mới mỗi giờ. Khi có bản mới, dashboard mở hộp thoại ghi thay đổi gì, với Cập nhật ngay và Để sau (hỏi lại sau một giờ). Muốn tự chạy thì dùng một lệnh:

Lên bản mới nhất
piagent-update

Khởi động lại dashboard sau khi cập nhật để giao diện mới có hiệu lực.

Terminal đang mở

Không cần đóng Terminal. Sau khi cập nhật, mọi Terminal đang mở (piagent và piagent studio) tự nạp bản mới khi rảnh và giữ nguyên cuộc trò chuyện. Terminal đang chạy task thì chờ task xong rồi mới nạp; footer ghi rõ đang chờ. Terminal cá nhân nạp lại extension của Piagent; Terminal công ty mở lại trong chính cửa sổ đó, trên đúng cuộc trò chuyện. Muốn yêu cầu lại bất cứ lúc nào:

Nạp bản đã cài vào mọi Terminal đang mở
piagent reload

Bản mới chạy trên một bản Pi khác thì Terminal cá nhân báo cần mở lại piagent.

Lệnh này làm gì, theo thứ tự

  1. Xác định bản đích và bản Pi mà bản đó pin.
  2. Cài đúng Pi host đó, rồi thay helper piagent-update.
  3. Kiểm tra version thật trên đĩa trước khi chạy installer.
  4. Với --project: migrate state của project và chạy piagent-doctor --strict-share.
Không chạy từ git checkout

piagent-update từ chối chạy khi package toàn cục là một bản link tới source repo, để không ghi đè code bạn đang sửa.

Tuỳ chọn thường dùng

LệnhDùng khi
piagent-update --checkChỉ xem có bản mới không.
piagent-update --dry-runXem sẽ cài gì, không đổi gì.
piagent-update --version X.Y.ZLên hoặc về đúng một bản.
piagent-update --project .Cập nhật và migrate project hiện tại.
--no-host · --no-package · --no-migrateBỏ qua từng bước.

Pin một bản cho cả team

Khi rollout cho team, cài đúng bản Pi host và đúng bản platform, rồi chạy installer ở chế độ stable. Bước --dry-run in ra những gì sẽ đổi.

Cài pin theo bản
npm install -g --ignore-scripts @earendil-works/pi-coding-agent@{{piHost}}
npm install -g --ignore-scripts @piagent/platform@{{version}}
piagent-install --stable --dry-run
piagent-install --stable

Vì cài từ package, .pi/settings.json ghi npm:@piagent/platform@<version>: giá trị giống nhau trên mọi máy, commit được cho cả team. Quy trình đầy đủ ở release & install policy.

Rollback

Rollback là thao tác có chủ đích, không tự động. Về một bản cụ thể bằng cùng lệnh cập nhật:

Về bản trước
piagent-update --version X.Y.Z --dry-run
piagent-update --version X.Y.Z

Chỉ muốn đổi Pi package mà giữ host: piagent-install --version vX.Y.Z --resolve-tag. Sau khi về bản cũ, chạy piagent-doctor trên project.

Gỡ cài đặt

piagent-uninstall mặc định chỉ in ra sẽ gỡ gì rồi thoát. Thêm --apply mới thực hiện, vì nó sửa Pi settings mà công cụ khác cũng ghi vào.

Xem trước, rồi gỡ
piagent-uninstall
piagent-uninstall --apply
npm uninstall -g @piagent/platform

Add-on, Pi host và state trong project là opt-in: --with-addons, --with-host, --project <path>.

Không bao giờ bị xoá

Credential, trust, session, todo và .pi/memory/ được giữ ở mọi tổ hợp cờ. File sinh từ template rồi đã sửa (AGENTS.md, .pi/settings.json) chỉ được liệt kê để bạn tự quyết.
