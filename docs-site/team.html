Team nên dùng như một chuẩn vận hành

Mỗi repo chỉ cần link package, chọn profile đúng và giữ tài liệu project-specific ở repo của dự án đó.

Việc nên làm

Chạy /onboard run, áp /profile auto, dùng /workflow, verify thật và ghi blockers rõ ràng.

Việc nên tránh

Đưa token, auth file, cache, session, private examples hoặc business logic riêng vào core package public.

Chuẩn handoff

Final response nên nói ngắn: đã đổi gì, verify nào đã chạy, có dùng subagent không, và còn rủi ro hoặc next step nào cần người review.

Release docs gate

Version docs mới chỉ được promote lên Vercel sau khi tag-triggered CI pass và stable dry-run resolve đúng commit SHA. Phải promote đúng tagged commit, không chèn merge commit hay docs-only edit khác. Domain canonical là piagent.io.vn; apex phải là Vercel primary và www redirect về apex.
