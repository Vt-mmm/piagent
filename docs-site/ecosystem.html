Piagent, Agent Watch và Agent Studio

Một dashboard, hai cách dùng model: tài khoản của bạn, hoặc model của công ty qua Agent Watch và Agent Studio, với Harness tự kiểm tra từng lượt.

Toàn cảnh

Một dashboard, hai cách dùng model

Piagent chạy trên máy từng thành viên. Ở chế độ cá nhân, nó dùng tài khoản model của chính bạn. Ở chế độ công ty, nó đi qua Agent Watch trên máy bạn và Agent Studio của công ty: công ty giữ key, chọn model và đặt quy trình kiểm tra cho cả team.

Thành phần

Mỗi phần làm một việc

Piagent

Coding agent trong Terminal (pi) và trên trình duyệt (piagent dashboard). Hai nơi dùng chung lịch sử: bắt đầu ở Terminal, xem tiếp trên trình duyệt.

Guard

Kiểm tra từng tool call trước khi chạy: file bảo vệ như .env, profile quyền, file quá lớn, sửa trên bản đã cũ. Push, publish và lệnh có mạng chờ bạn duyệt đúng một lần.

Agent Watch

Ứng dụng macOS giữ key công ty trong Keychain và nhập cấu hình cho Piagent. Mỗi lượt nhận quyền ngắn hạn; model và các lệnh không bao giờ đọc được key.

Agent Studio

Máy chủ của công ty: thành viên, key, ngân sách, usage theo ngày và Harness của team. Studio chọn model cho từng vai (main, research, review) và mức suy luận.

Một lượt ở chế độ công ty

Từ tin nhắn tới "Check đã qua · Review không có lỗi chặn"

Bạn nhắn việc cần làm

Viết như nói với đồng nghiệp, chọn model agent-watch-auto trong nhóm Công ty.

Studio cấp một lượt

Agent Watch xin quyền ngắn hạn; Studio chọn model cho agent chính theo Harness của team.

Agent làm trong sandbox

Đọc, sửa và chạy lệnh trong project, không có mạng. Cần mạng thì xin bạn duyệt đúng một lệnh.

Harness kiểm tra

Chưa có check nào qua trên code cuối thì yêu cầu chạy; rồi một subagent review bản sửa. Lỗi chặn được gửi lại cho agent, tối đa số vòng team đặt.

Kết quả ghi dưới câu trả lời

Ví dụ "Check đã qua trên code cuối · Review không có lỗi chặn". Bạn có thể Dừng bất cứ lúc nào và Tiếp tục sau.
