Command ngắn, rõ, ít token burn

Slash command gói sẵn policy và flow; một inspector menu duy nhất cho diff, command, safety và context. Thành viên không cần nhớ nhiều command rời.

Session basics

/login /model /commands /piagent-status /piagent-inspector /piagent-orchestration /usage /usage efficiency /task-preflight /context preflight /name /fresh /session

Dùng để setup session, chọn model, xem profile/usage/orchestration và quyết định có cần fresh session trước task lớn không.

Project profile

/profile /profile list /profile auto /profile setup /profile tech /profile tech setup /profile fullstack /profile be-fe

Áp profile trực tiếp hoặc mở select option để chọn profile/tech stack. Output ngắn, không yêu cầu model giải thích dài.

Implementation workflow

/workflow /workflow task /workflow plan /workflow review /workflow scout /workflow discuss

Gói sẵn read context, task contract, implementation, verify evidence và final handoff.

Git handoff

/workflow commit /workflow pr git status git diff

Không cần namespace /git. Commit/PR đi qua workflow guard; push và stage rộng như git add -A cần xác nhận.

Fresh sessions

/fresh task /fresh scout /fresh be-to-fe

Dùng khi context đã nặng hoặc cần một session sạch cho workflow mới.

MCP

Subagents

/subagents-doctor /subagents-models /subagents-fleet /subagent-cost

Kiểm tra runtime, model routing, background runs và cost. Daily flow vẫn solo-first; subagents dùng cho scout/planning/review độc lập.

Product visibility

Xem runtime đang quyết định gì

Các command này đọc state deterministic, không cần model giải thích và không bắt buộc trong workflow hằng ngày.

Preflight trước task
/task-preflight --json Review current repository state

Xem intent, risk, scope, runtime, solver route, phase, tool/helper recommendation, backend, approval và blocker trước khi bắt đầu.

Live task status
/piagent-status

Đọc Task Contract, checkpoint, verifier, recovery, helper, resume state và terminal receipt. Receipt chỉ approved khi hard completion gate trên working tree hiện tại pass.

Activity, diff và context
/piagent-inspector

Một menu duy nhất cho summary, files, commands, security, context và toggle. Panel bốn dòng tự hiện sát phía trên footer native; xanh lá là ổn, vàng cần chú ý, đỏ là failure/safety hoặc context từ 80%. Command chỉ đọc state local, không gọi model.

Efficiency có nguồn
/usage efficiency

Xem context/tool utilization, verify, repair, retry và helper usage. Giá trị runtime không đo được giữ là null, không ước đoán.

Helper policy
/piagent-orchestration

Xem solo-first policy, read-only roles, reviewer/Oracle recommendation, owned budget và one-writer invariant.

Diff rõ nguồn, token không ước lượng.

Footer status dùng file task đã quan sát để cập nhật nhanh; view files tính exact snapshot delta và đánh dấu mixed-working-tree nếu task đụng file đã dirty từ trước. Pi chỉ cung cấp model usage theo turn/session, nên token theo từng built-in tool luôn hiện unavailable.
