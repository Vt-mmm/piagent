Sửa trang này

Session basics

/login /model /piagent-status /piagent-inspector /piagent-orchestration /usage /usage efficiency /task-preflight /context preflight /name /new /session

Dùng để setup session, chọn model, xem profile/usage/orchestration và quyết định có cần mở session mới (/new) trước việc lớn không.

Project profile

/profile /profile list /profile auto /profile setup /profile tech /profile tech setup /profile fullstack /profile be-fe

Áp profile trực tiếp hoặc mở select option để chọn profile/tech stack. Output ngắn, không yêu cầu model giải thích dài.

Giao việc

lời thường chỉ đọc, không sửa lập plan trước review diff

Từ bản 1.9.0 không còn /workflow, /task hay task contract: nói việc cần làm bằng lời thường; guard kiểm tra từng tool call.

Git handoff

commit bằng lời thường draft PR bằng lời thường git status git diff

Không cần namespace /git. Commit/PR là yêu cầu thường; push, ghi lên GitHub và stage rộng như git add -A cần xác nhận.

MCP

Kiểm tra và cấu hình tool servers theo preset core, popular hoặc design.

Subagents

/subagents-doctor /subagents-models /subagents-fleet /subagent-cost

Kiểm tra runtime, model routing, background runs và cost. Daily flow vẫn solo-first; subagents dùng cho scout/planning/review độc lập.

Product visibility

Xem runtime đang quyết định gì

Các command này đọc state deterministic, không cần model giải thích và không bắt buộc trong workflow hằng ngày.

Preflight trước task
/task-preflight --json Review current repository state

Xem intent, risk, scope, runtime, solver route, phase, tool/helper recommendation, backend, approval và blocker trước khi bắt đầu.

Trạng thái session
/piagent-status

Profile, guard, runtime và model đang dùng của session. Không sửa file, không chạy lại check và không mở lượt model.

Activity, diff và context
/piagent-inspector

Một menu duy nhất cho summary, files, commands, security, context và toggle. Panel bốn dòng tự hiện sát phía trên footer native; xanh lá là ổn, vàng cần chú ý, đỏ là failure/safety hoặc context từ 80%. Command chỉ đọc state local, không gọi model.

Efficiency có nguồn
/usage efficiency

Xem context/tool utilization, verify, repair, retry và helper usage. Giá trị runtime không đo được giữ là null, không ước đoán.

Helper policy
/piagent-orchestration

Xem solo-first policy, read-only roles, reviewer/Oracle recommendation, owned budget và one-writer invariant.

Diff rõ nguồn, token không ước lượng.

Footer status dùng các file đã quan sát trong session để cập nhật nhanh; view files tính exact snapshot delta và đánh dấu mixed-working-tree nếu lượt làm việc đụng file đã dirty từ trước. Pi chỉ cung cấp model usage theo turn/session, nên token theo từng built-in tool luôn hiện unavailable.

Skill và package tùy chọn

Kiểm tra chất lượng test, chạy vòng thử nghiệm

Rà soát test
/skill:test-audit rà soát test của module thanh toán

Skill test-audit đi kèm Piagent: chặn test mới không bảo vệ hành vi nào, tìm test trùng, test bám vào cách cài đặt và code chỉ tồn tại để phục vụ test. Agent tự dùng khi viết hay sửa test; gõ lệnh trên để rà cả một vùng.

Vòng thử nghiệm
git switch -c experiment/toc-do-test

Nếu cài thêm package có vòng thử nghiệm tự động (run_experiment, log_experiment): guard kiểm lệnh thử như mọi lệnh shell, và chỉ cho vòng lặp chạy trên nhánh experiment/ hoặc worktree riêng, bắt đầu khi không còn thay đổi chưa commit, vì mỗi lần bỏ một ý tưởng nó xóa mọi thay đổi chưa commit.
