Docs / Operate / Context Engine

Ít context hơn, giữ nguyên chất lượng model

Index local, retrieval có xếp hạng, tool loading theo task, semantic compaction và telemetry minh bạch cho Agent Watch.

Tool theo task

Pi chỉ đưa governance, policy, code retrieval, knowledge, onboarding hoặc usage vào prompt khi task cần. Runtime guard vẫn chạy ngầm.

Index local

FTS5, symbol và import graph nằm trong .pi/piagent-state/context-engine/. Storage chỉ cho OS account hiện tại; policy đổi sẽ retry FTS rebuild và VACUUM đến khi purge xong.

Context có xếp hạng

Explicit path, lexical match, symbol, Git, test relation, positive feedback và graph rank được gộp trước khi pack vào hard token budget.

Semantic compact

Giữ goal, quyết định, changed files, verify và blocker. Bỏ log lặp, source excerpt và kế hoạch đã bị thay thế.

Test impact

Đi ngược import graph từ file thay đổi để đề xuất dependent files và focused tests trước full suite.

Agent Watch

Event local có session, model, thinking, tool surface, retrieval confidence, tỷ lệ context thực dùng và waste metrics; không lưu prompt hay output thô lần hai.

Index có chứa source body

Protected paths và secret files không được index. Directory dùng mode 0700; database, WAL và SHM dùng 0600. Refresh bình thường dùng SQLite core + FTS5 secure-delete. Full FTS rebuild và VACUUM chỉ chạy khi exclusion policy đổi hoặc một purge trước bị gián đoạn, không chạy trên mỗi prompt hay mỗi refresh.
