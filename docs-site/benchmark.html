Giới hạn của kết luận

Đây là public synthetic regression do maintainer xây dựng, không phải benchmark độc lập chứng minh Piagent tốt hơn trên mọi repository hoặc model. Generated values không tạo task family độc lập. Generalization cần external family-disjoint holdout, reference/mutation/human-calibration manifest, candidate freeze và shadow/canary task thực tế.

Chạy lại production benchmark
piagent-benchmark --production \
  --surfaces piagent,codex-cli \
  --model openai-codex/gpt-5.6-sol \
  --thinking xhigh
